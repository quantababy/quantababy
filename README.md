### 🚀 Featured Projects

#### 1. 🔗 [VeritasChain](https://github.com/quantababy/veritaschain) — *Decentralized AI Fact-Checking Pipeline*
> **Tech:** `FastAPI` `WebSockets` `React/TypeScript` `LangChain` `FAISS` `PyTorch Geometric` `Solidity` `IPFS`
- Architected a real-time **FastAPI + WebSocket** backend streaming claim submissions and verified verdicts to a React/TypeScript dashboard.
- Engineered **Trie/Heap-based claim deduplication**, a **LangChain/FAISS RAG pipeline**, and a **PyTorch Geometric GNN** for source-trust scoring.
- Integrated **Solidity & Web3.py** for immutable, IPFS-backed verdict storage with **451 passing unit/integration tests**.

#### 2. 📈 [VolatilityForge](https://github.com/quantababy/VolatilityForge) — *Quantitative Market Volatility Forecasting*
> **Tech:** `Python` `pandas` `yfinance` `GARCH` `HAR-RV` `LightGBM` `Streamlit`
- Built an end-to-end quantitative pipeline aligning SPY/VIX market data to engineer volatility features and forward realized-variance targets.
- Implemented **EWMA, GARCH, GJR-GARCH, HAR-RV, and LightGBM** forecasts across 1-day and 5-day horizons using expanding-window walk-forward validation.
- Reduced mean **QLIKE by 18.54%** ($0.4576 \rightarrow 0.3727$) and **MSE by ~2.57%** over 1,196 out-of-sample observations using a 5-day HAR-RV smearing-correction study, complete with transaction-cost-aware backtests.

#### 3. 🪙 [Cryptographic Wallet / Blockchain & Babycoin ICO](https://github.com/quantababy/cryptographic-wallet) — *PoW Blockchain & Token Sale*
> **Tech:** `Python` `Flask` `Solidity` `SHA-256` `REST APIs`
- Built a Proof-of-Work blockchain API featuring SHA-256 hash-linked blocks, transaction validation, peer-node registration, and longest-valid-chain consensus.
- Developed a **Solidity Smart Contract** for the Babycoin ICO supporting a 1,000,000-token cap, dynamic INR conversion, and investor equity tracking.
